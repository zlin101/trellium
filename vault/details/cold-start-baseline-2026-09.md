1. 每个场景必须开一个**全新会话**（无聊天历史）执行；主会话 Agent 不得代答。

4. 每条记录一行，跑完即填，不事后回填。
5. **先记录、后纠正**：每个会话先保存 Agent 首次回答原文与全部指标，之后才允许纠正或讨论；纠正内容单独记，不计入首答。

### 实验设计备忘（后续轮次修正用）

1. **污染路径**：本协议文件位于 `vault/details/`，处于 AGENTS.md 的细节路由上，S5/S6/S7 被动读到评分 key。未来轮次应把场景卡与评分 key 移出 vault 读取路径（仓库外或路由外位置），或接受"准确率为上限值"的口径。

3. **bytes/耗时未逐项采集**：本轮以文件数与工具调用数为主；若未来需要 ≥30% 降本的 A/B 判定（条件 3），必须先补齐字节级基线。
